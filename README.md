# McKelvey Fine Art Services: Website

Built with [Vite](https://vite.dev) + TypeScript.

## Structure

```
index.html            Entry page
src/main.ts           TypeScript entry point
src/style.css         Styles
src/assets/           Images/files imported from code (optimized by Vite)
public/               Files served as-is (favicon, robots.txt, etc.)
MEETING-QUESTIONS.md  Questions to ask before building
```

## Commands

```bash
npm install       # first time only
npm run dev       # start local dev server with live reload
npm run build     # type-check + build for production into dist/
npm run preview   # preview the production build
```
